# Migrating to v0.28.0: Removal of legacy IBM Qiskit Runtime Service names

## Overview

v0.28.0 removes the legacy IBM Qiskit Runtime Service names that were
deprecated in [v0.23.0](./0.23.0.md). Only the IBM Quantum Compute Service
names are supported from this release.

If you already migrated to the new names in v0.23.0 or later, no action is required.

## How to migrate

Follow the steps in the [v0.23.0 migration guide](./0.23.0.md#how-to-migrate).
