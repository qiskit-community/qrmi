Migrating to v0.28.0: Removal of legacy IBM Qiskit Runtime Service names
========================================================================

Overview
--------

v0.28.0 removes the legacy IBM Qiskit Runtime Service names that were
deprecated in :ref:`v0.23.0 <v0.23.0>`. Only the IBM Quantum Compute Service
names are supported from this release.

If you already migrated to the new names in v0.23.0 or later, no action is
required.

How to migrate
--------------

Follow the steps in the
:ref:`v0.23.0 migration guide <v0.23.0>`.
