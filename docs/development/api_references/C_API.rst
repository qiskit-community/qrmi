C API Reference
===============

.. rst-class:: lead

    Detailed documentation for QRMI's C API, including available functions, data structures, and usage information.

Unlike QRMI's Python API documentation, which is built and served using Sphinx, the C API documentation is built using C's `Doxygen` package.
